# python-daily-practice

Python daily practice exercises.

## Summer Roadmap (Beginner Friendly)

This plan is designed for a true beginner who is learning in class, at an internship, and at home.

### Main goal by end of summer
- Build confidence in Python fundamentals.
- Finish 2 small portfolio projects.
- Keep clear proof of progress for graduate school applications.

### Weekly roadmap (12-week example)
1. **Weeks 1-2: Python basics**
   - Variables, types, `if/else`, loops, functions, lists/dictionaries.
   - Daily practice: 30-60 minutes.
2. **Weeks 3-4: Problem solving**
   - Write small scripts and solve beginner coding problems.
   - Focus on reading errors and debugging.
3. **Weeks 5-6: File handling + modules**
   - Read/write text files, import modules, use `pip`.
   - Start Project 1 (small automation script).
4. **Weeks 7-8: Data + APIs**
   - Work with CSV/JSON, call a simple API.
   - Finish and document Project 1.
5. **Weeks 9-10: Object-oriented programming**
   - Classes, objects, methods, basic design.
   - Start Project 2 (internship-related if possible).
6. **Weeks 11-12: Review + portfolio**
   - Finish Project 2, clean both projects.
   - Practice explaining your code clearly.

### Weekly documentation checklist (for graduate school)
- Keep a learning log (`date`, `topic`, `what I built`, `what I struggled with`, `next step`).
- Save code links and short reflections for each project milestone.
- Track internship tasks with outcomes and tools used.
- Keep a folder with:
  - Resume updates
  - Statement of purpose draft
  - Recommender list and deadlines
  - Project summaries (problem, solution, result, lessons learned)

### Suggested weekly rhythm
- **Class days:** review notes + 1 practice exercise.
- **Internship days:** write down 1 thing learned at work.
- **Home days/weekend:** work on projects and update documentation.

### Success rule
Small daily progress is enough. Consistency beats intensity.
